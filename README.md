# NAVADA x Booster Robotics

Partnership site for www.navadarobotics.com. Next.js (App Router), Tailwind CSS v4, shadcn/ui components and Motion.

- Hero image: `public/hero.webp`
- Lifestyle images: add files to `public/gallery/` and list them in `lib/gallery.ts`

```bash
npm install
npm run dev
```
